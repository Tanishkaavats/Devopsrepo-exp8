# CI/CD Pipeline using Jenkins and Docker

## Objective
To create a CI/CD pipeline using Jenkins running inside Docker to build and deploy a Python application.

## Tools Used
- Jenkins
- Docker
- GitHub
- Python

## Project Structure
- app.py → Sample Python application
- Dockerfile → Used to build Docker image
- Jenkinsfile → Defines CI/CD pipeline

## Steps
1. Jenkins runs inside Docker
2. Code is pushed to GitHub
3. Jenkins pulls code
4. Docker image is built
5. Container is executed

## Output
The application runs successfully using Docker through Jenkins pipeline.
